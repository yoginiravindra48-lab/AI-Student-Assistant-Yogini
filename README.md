# 🤖 AI Student Assistant

An AI-powered study assistant for engineering students.

## 🚀 Features

- 💬 AI Chatbot
- 📚 Subject-based assistance
- 📝 Study Notes Generator
- 🧠 Interactive Quiz Generator
- 🎯 Quiz Score
- 🦙 Local AI using Ollama

## 🛠️ Technologies Used

- Python
- Streamlit
- Ollama
- Llama 3.2

## 🏗️ Architecture

Student
↓
Streamlit UI
↓
Python
↓
Ollama
↓
Llama 3.2
↓
AI Response
